# 核心方法

详细公式与计算步骤见[技术报告](technical_design.md)。

## 坐标与时间

+X东、+Y北、+Z上；方位角从北顺时针，倾角相对水平面。平面图沿世界Z轴俯视。

[NOAA太阳方程](https://gml.noaa.gov/grad/solcalc/solareqns.PDF)：扬州32.4°N、119.4°E，UTC+8，2025年，每小时取中点。

## 单板基准出力

MATLAB逐时计算倾斜面直射、Perez散射及地面反射，按含风速的NOCT关系估计电池温度T_c：

```text
G = G_b + G_d + G_r
P = P_STC · (G/G_STC) · [1 + k_P·(T_c − 25°C)]
e(t) = 时段平均功率 × 1 h
```

G_STC=1000 W/m²；k_P以℃⁻¹代入，%/℃数值除以100。各型号及角度组合生成单板Wh时序，供插件查表。

## 排布

安装面跨度B、板实体投影跨度P、净距g（mm）：

```text
节距 = P + g
数量 = floor((B + g)/(P + g))
g_max = max(0, 10·floor(min(P, B − 2P)/10))
```

滑条5 cm、手输1 cm；上限为程序规则。板实体8角点的面内投影凸包须完全处于安装区域，包含孔洞校核。

在固定型号、角度、净距下，比较一个节距内的网格起点δ：

```text
pᵢⱼ(δ) = (退让 + δₓ + i·节距ₓ, 退让 + δᵧ + j·节距ᵧ)
δ* = argmax[δ∈候选集] Σᵢⱼ 1(板投影满足全部约束)
```

候选含居中起点、均匀采样及边界对齐位置，并局部细化；通道生成后按同样规则重排。仅比较统一网格平移，不搜索各子区独立起点、混合转向等全部装箱方式，不保证全局最多。通道占板数在最终同一起点下比较有、无通道的差值。

立面wall、围墙fence强制贴合；fence板长超过面高时仅允许越过上边界。平屋面方位角可调，限0°—359°、步长1°。斜屋面方位角固定为屋面实际朝向，绝对倾角可在屋面坡度至90°之间调整，取最低值时贴合。固定朝向缺少对应数据时只保留几何，不借用其他角度出力。

## 通道与退让

在安装面局部坐标中计量距离。板实体投影凸包P须处于有效屋面内，且满足：

```text
dist(P, 外边界) ≥ 外退让；dist(P, 孔洞及人工禁布区边界) ≥ 内部退让
dist(P, 通道中心线) ≥ 通道净宽/2；Area(P ∩ 人工禁布区) = 0
```

禁布矩形沿安装面局部正交轴，在SU中以两个对角点确定；入口吸附外边线或角点。通道为折线的半净宽缓冲区，支路中心线相接；除入口连接段朝向屋外的开口外，完整净宽不得越过屋面边界、孔洞或禁布区。

自动规划：按局部坐标以尺度L划分检修分区，为每个有板分区选择靠近其板群中心的接入点。边界内缩线、可容纳通道的排板间隙中线及辅助正交网格组成候选图；边逐段精确校核净宽。以新增占板数和长度加权寻路，连到入口后合并支路；比较两种权重方案，先取初排占板少者，再取累计长度短者。固定所选通道后平移重排；调整角度、间距、退让或禁布区后重新规划。

净宽默认0.8 m、L默认15 m均为可调设计参数；L表示分区边长，不等于规范规定的通道间距，也不保证逐板触达。算法为有限候选寻优，不宣称全局最优或完成施工合规审查。[SJG 220—2026第4.2.9条及说明](https://zjj.sz.gov.cn/attachment/1/1692/1692731/12682113.pdf)提出检修通道宜≥0.6 m、临空女儿墙侧≥1 m、兼作疏散通道时按相应要求≥1.1 m；属深圳地方标准，不作为扬州项目的强制参数。

## 阴影几何

接收板原点o、单位法向n，太阳方向s；遮挡点p沿−s投影：

```text
p′ = p − s·[(p − o)·n/(s·n)]
H_i = (周边投影 ∪ 光伏投影) ∩ 板i
f_i = 1 − Area(H_i)/Area(板i)
```

只保留接收板向阳侧的遮挡几何，剔除自身；周边可见面按实际三角网读取，保留孔洞及嵌套变换。扫描线求多边形并集，重叠只计一次。无正面直射时f_i=1。

候选筛选：太阳位于地平线上方时，最高点不高于全部接收板最低点的周边面可永久排除；其余面预建包围盒层级，逐时沿太阳方向投影包围盒，与阵列投影范围不相交则整支排除，余下按空间分格精确裁剪。坐标变换缓存于当前几何快照；不设固定距离截断。

无周边遮挡、同尺寸同朝向且板实体不相交时，可用整体投影并集直接求总受光率：F=Area(∪R_i)/(N·W·L)。

## 出力

```text
原始 E₀(t) = Σ e_i(t)
修正 E₁(t) = Σ [e_i(t)·f_i(t)]
全年减少率 = 1 − ΣE₁/ΣE₀
```

按各板实际型号和世界角度查表；无对应角度时不借用邻近数据。先逐时修正，再求月均逐时和月总量；原始总量为0时减少率取0。基准时序已含散射、地面反射及温度影响；几何修正对总电量统一按面积折减，不另算各辐射分量、温度响应或电气失配。

CSV：365日期行×24时段列，单位Wh；SVG导出矢量水平俯视图。CSV与SVG使用独立按钮。
