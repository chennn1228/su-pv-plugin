# 核心方法

## 1. 坐标与太阳

+X东、+Y北、+Z上；方位角从北顺时针，倾角相对水平面。

太阳方向由[NOAA方程](https://gml.noaa.gov/grad/solcalc/solareqns.PDF)即时计算。当前固定扬州32.4°N、119.4°E，UTC+8，参考年2025；每小时取中点。

## 2. 排布与间距

B：安装面尺寸；P：板实体投影包围跨度；g：该方向净距。单位mm。

```text
节距 = P + g
数量 = floor((B + g)/(P + g))
g_max = max(0, 10·floor(min(P, B − 2P)/10))
```

滑条5 cm，手输1 cm；上限是程序规则，不是规范要求。

板实体投影须完整位于安装区域内；以投影凸包与区域外部的交集面积校核，不能只检查顶点。

平铺排布：板面平行屋面，净距在屋面内计算，高度沿屋面法向；横铺只在面内旋转90°。实际角度不按出力表网格取整。

选面时按世界法向初始化贴合姿态，之后方位角独立调整。“贴合屋面”恢复屋面坡度与坡向。板面倾角为绝对水平角，下限为屋面坡度，上限还须满足板面法向与屋面法向点积≥0（两面夹角≤90°）。实际角度无对应数据时不查邻近格点；防穿面由实体8角点校核与法向抬升保证。

## 3. 互遮挡

同尺寸平行单面板，宽W、长L，无厚度。u、v、n为板宽、板长、法向单位向量；s指向太阳。板i原点在(u,v,n)中为(aᵢ,bᵢ,cᵢ)。

```text
qᵢ = (aᵢ − cᵢ(s·u)/(s·n), bᵢ − cᵢ(s·v)/(s·n))
Rᵢ = [qᵢₓ,qᵢₓ+W] × [qᵢᵧ,qᵢᵧ+L]
fᵢ = 1 − 板i上的阴影并集面积/(W·L)
F = sum(fᵢ)/N
```

沿太阳方向投影到与板平行的参考面，只取前方板(cⱼ>cᵢ)的重叠；空间分格筛选，并集避免重复扣减。无正面直射时F=1。

## 4. 出力修正

e(t)：单板原始时段电量；N：实际保留板数。

```text
原始 E₀(t) = N·e(t)
修正 E₁(t) = E₀(t)·F(t)
全年减少率 = 1 − sum(E₁)/sum(E₀)
```

先逐时修正，再求月均逐时或月总量；原始全年总量为0时减少率取0。仅按面积折减，不含建筑遮挡、散射分解、反射及电气失配。

CSV导出当前分支：365个日期行×24个小时列，每格为该时段电量Wh；阵列为总量。

## 5. 整体投影并集

同尺寸平行板且实体互不重叠时，总受光比例可直接求：

```text
F = Area(R₁ ∪ … ∪ R_N)/(N·W·L)
```

扫描线＋线段树求整体并集，O(N log N)。界面可选此法或逐板投影，默认整体并集；阴影图仍使用逐板结果。本地内核测试约快1.5～3倍。

[长排解析式](https://doi.org/10.1063/5.0202220)仅适合相应规则排布，不能直接套用有限、缺板阵列。
